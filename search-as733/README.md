
## Поиск двух слабо связанных автономных систем 
Пусть есть 2 вершины в графе: A (связана с B, C, D, E) и B (связана с A, F, H, G, K). \
Как видно, из A в B можно попасть либо напрямую: A-B, либо более длинным путём, чем через одну из вершин. Будем называть такую пару вершин слабо связанными. \
Выберите один из файлов в архиве на своё усмотрение, скачайте данные графа и определите две слабо связанные вершины с числом рёбер не менее 10-и . \
В качестве ответа приложите: исходный код, название выбранного файла и результат работы программы.
